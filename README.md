## Descripción del trabajo

Este repositorio contiene la resolución del TP4 de Informática Médica. El trabajo consiste en consultar y corregir una base de datos médica (pacientes, médicos, consultas y recetas) usando el lenguaje **SQL**, y en practicar el manejo de versiones con **Git y GitHub**.
